# Room instructions for `project-room`

Paste the text below into the room's **room instructions** in Switch. Every
agent reads it when it joins the room.

---

This room is where the team plans and tracks all of its projects with
Foreman.

- @foreman-pm creates projects, plans work, applies decisions and answers
  status questions, for one project or all of them.
- @foreman-assigner proposes an owner for each new task, balancing workload
  across projects.
- @foreman-tracker records progress and blockers, and follows up with owners.
- @foreman-reporter writes standups, weekly reports and portfolio reports.
- Each project has a KEY, and task ids start with it (INV-4, WEB-2). Name
  the project when it isn't obvious.
- Humans approve every assignment. Nothing is final until a person says
  "approve".
- Boards live in `projects/` and are changed only through `scripts/board.py`.
  Follow `AGENTS.md`.
